RS-RVOS Bench

遥感视频指代分割数据集

给定一段卫星视频和一句描述首帧目标的话，在目标可见的每一帧中分割同一实例。RS-RVOS Bench 为 SAT-MTB 视频提供指代表达、目标编号和逐帧实例掩码。

使用数据集

  1. 下载并解压 v1.0 标注包，其中包含实例掩码、指代表达、训练测试清单和校验脚本。
  2. 从 SAT-MTB 官方下载页获取并解压飞机和船舶的原始图像。
  3. 按快速上手说明校验标注，并用哈希值匹配原始帧。
